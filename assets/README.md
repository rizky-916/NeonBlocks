# Sound assets

| File | Used for |
|------|----------|
| `music.mp3` (or `music.ogg`) | Looping background music |
| `clear.mp3` (or `.wav` / `.ogg`) | Line clear |
| `drop.wav` (or `.ogg` / `.mp3`) | Piece locks (optional, not included) |

Press **M** in game to mute. The game still runs if any file is missing or no audio device is available.

See [CREDITS.md](CREDITS.md) for the source and license of the included sounds. If you add your own
files, only use audio you have the rights to and credit it there.
